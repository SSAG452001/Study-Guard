How it works

Two layers of protection working together.

  1. DNS filter (local VPN)
    Study Guard answers "site not found" for blocked domains and passes everything else through normally.
  2. App blocker (Accessibility)
    Detects a blocked app opening during Study Mode and returns you to the home screen.
  3. You choose what to block
    Pick AI, distractions, or both. Start Study Mode and focus.

Blocked by Google Play Protect?

This is normal for apps installed outside the Play Store. Study Guard is a student project, not a virus. Use Option 1 first.

  1. Option 1: Install anyway. When the "Blocked by Play Protect" message appears, tap More details, then Install anyway. If it asks to scan the app, choose Don't send.
  2. Option 2: Turn Play Protect off for a moment. Open the Play Store app, tap your profile picture, then Play Protect, then the ⚙️ settings icon. Turn off Scan apps with Play Protect and confirm. Install Study Guard, then turn it back on.
  3. Samsung phones: Also switch off Auto Blocker in Settings > Security and privacy while installing.
  4. Still won't install? Allow Install unknown apps for the app you opened the file from (Files, Chrome, WhatsApp). If an older Study Guard is installed, uninstall it first. If the file seems damaged, download it again over Wi-Fi.

Setup after installing

  1. Open Study Guard, tap Enable app blocking and switch on Study Guard in Accessibility. On Android 13+, first allow "Restricted settings" from App info (⋮ menu).
  2. Tap Start Study Mode and accept the VPN prompt. It is only a local filter.
  3. In Chrome turn off Use secure DNS, and set Android Private DNS to Off so blocking cannot be bypassed.
